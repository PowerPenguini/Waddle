# Triage labels

The engineering skills use five canonical triage roles.

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Work is waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation |
| `wontfix` | `wontfix` | The issue will not be implemented |

When a skill refers to a triage role, use the corresponding value in the `Status:` field.
