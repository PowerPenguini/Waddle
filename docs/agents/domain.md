# Domain docs

Waddle uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that affect the area being changed.
- If an expected document does not exist, continue without creating it automatically.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issues, specifications, implementation plans, tests, and code.

Do not replace a defined term with a synonym listed under its `_Avoid_` entry.

If the required concept is missing, reconsider whether an existing term covers it. Record a genuine vocabulary gap for the `domain-modeling` skill.

## Architecture decisions

Store repository-wide ADRs under `docs/adr/`.

If proposed work contradicts an ADR, identify the conflict explicitly instead of silently replacing the decision.
