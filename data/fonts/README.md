# Bundled fallback fonts

Unmodified Adwaita Fonts 50.0 from the Arch Linux `adwaita-fonts` 50.0-1 package.
Upstream: https://gitlab.gnome.org/GNOME/adwaita-fonts

- Adwaita Sans: variable upright family, including regular and semibold weights.
- Adwaita Mono: regular and bold upright faces.

These files are embedded in Waddle. Desktop font settings take precedence;
Fontconfig provides the system fallback when available. These bundled families
cover systems without matching installed fonts, GSettings, or Fontconfig.

The fonts retain their SIL Open Font License 1.1, copyright notices, and names.
