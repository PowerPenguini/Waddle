# 03: Wayland system Copy and Paste

**What to build:** Exchange multi-entry Copy payloads between PolarExp and other Wayland applications through the system clipboard.

**Blocked by:** 01: Multi-entry clipboard Transfer inside PolarExp.

**Status:** ready-for-agent

- [ ] One offer publishes all agreed clipboard MIME formats.
- [ ] Paste accepts bounded absolute local file URIs.
- [ ] Malformed, oversized, mixed-generation, and remote payloads are rejected safely.
- [ ] Copy works in both directions with a compatible Wayland application.
