# Waddle flat file icons

Solid colored silhouettes with white file-type symbols on a 24-unit grid. No outer outlines, shaded folds, raised badges, highlights, gradients, or shadows. Sheets retain a clipped corner for recognition; the folder is a single theme-accent shape. Archives use a zipper, presentations use a chart, and PDF lettering is vector geometry.

Colors: folder uses the active theme accent, generic #858F9B, document #6B869A, code #567CB5, image/spreadsheet #4E8A70, audio/video #8870AE, archive/presentation #B0824F, PDF #BF6868. Existing typography, type mappings, system icon preference, and sidebar tint behavior are unchanged.

Delicate refinement: soften saturation, reduce the heaviest symbol strokes from 1.5 to 1.2 units, and inset marks by 10% (5% for PDF lettering). Keep the solid silhouettes and small-size legibility.

Folder artwork stays symbolic in grid/list views, the sidebar, and drag previews, so theme changes recolor it. File artwork retains its fixed palette.
